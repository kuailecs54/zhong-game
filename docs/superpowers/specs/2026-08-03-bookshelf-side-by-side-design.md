# 设计：书架书脊并排改造（单层优先 + 自动加层）

## Context

当前书架（`SortGrid.vue`）采用"**每种去重书各占一层**"（`layerData` 按首次放置顺序分配层号），同种书合并为 1 本书脊 + ×N 角标；书脊宽固定 18px 不随数量增厚。实际游玩反馈：小关卡书种少时层数即书种数、书站得矮，视觉上不像真实书架。

用户希望改为**书本并排竖着排放**：同种书合并为 1 本书脊 + ×N 角标（书脊宽度固定，不随数量增厚），书种少时单层并排，单层放不下时自动加层（自下而上填充）。矩阵模式（`MatrixGrid.vue`）同步改造：格内固定宽书脊 + ×N 角标，替换当前"堆叠 3 本 + +N"。

数据流：`gameStore.placeCard()` 正确分支 `shelvedBooks.push()` 保留放置顺序，本设计不改数据模型，只改渲染算法。

## Goals / Non-Goals

**Goals:**
- 每列书架改为**书脊并排**：同种合并为固定宽书脊 + ×N 角标，宽度不随数量增厚。
- **单层优先**：书种少时单层并排；超过每层容量自动加层（自下而上填充，无预规划空层板）。
- 每层容量 = 按单元宽度动态计算（书脊固定宽 20px，窄单元最小 14px）。
- 书脊书名**竖排单列不折行**，超长截断。
- 矩阵模式格内改固定宽书脊 + ×N 角标（替换堆叠）。
- 幽灵预览：已有同种书→贴其书脊后；新书→最低有空位层末尾。

**Non-Goals:**
- 不改游戏规则（计分、生命、连击、冰冻、星级）与数据文件。
- 不改拖拽放置交互系统（pointerdown 捕获、松手吸附、失败提示）。
- 不做后端、持久化或跨端改动。

## Decisions

### 1. 分层算法：按容量填层（替换"每书种一层"）

`SortGrid.vue` 的 `layerData` 重写：

- **每层容量** `capacity = floor(单元可用宽 / (书脊宽 + 书间gap))`，动态计算。
  - 单元宽：2~3 列关 ~110px，5 列关 ~94px，10 列关 ~43px（`GameView.vue` 面板宽度公式不变）；可用宽 ≈ 单元宽 − 12px（含既有 padding）。
  - 书脊宽：常规 20px；单元窄时缩至 **min 14px**。
  - 示例：110px 单元 → 4 本/层；94px → 3 本/层；43px → 1~2 本/层（10 列关每列仅需 ~3 本，1~2 层即可）。
- **填充**：自下而上。第 0 层放满才开第 1 层；新书总是进入最低有空位层的末尾。
- **同种合并**：层内按 `process.id` 分组，同种合并为 1 本书脊 + 红色 ×N 角标；书脊宽度固定，不随 count 增厚。
- 层数 = 实际需要（`ceil(书种数 / 容量)`），不预规划空层板；至少 1 层。

### 2. 书脊视觉与文本

- 竖排直立（保留 `writing-mode: vertical-rl`），固定宽（20px / 窄单元 14px）。
- 书名竖排**单列不折行**：`overflow: hidden` + `max-height` 截断（不换行成两列）。
- 层结构：`层板(board) + 书脊区(spines)` 保留；书脊区水平排列、`justify-content: flex-start`（从左到右排），书脊 `align-items: stretch` 撑满层高。
- 保留层高随层数递减的透视效果（现有 nth-child 规则可简化）。

### 3. 幽灵预览与交互高亮

- **已有同种书**：幽灵预览显示在该书所在层书脊的紧邻后方。
- **新书**：显示在最低有空位层的末尾。
- 可放置高亮与拖拽命中逻辑不变；幽灵书脊虚线描边 + 书名，不占用真实层容量。

### 4. 矩阵模式改造

`MatrixGrid.vue` 每格 = (过程组 × 知识领域) 唯一交叉，格内只有 1 个过程：

- 格内改为**固定宽书脊 + ×N 角标**（重复合并），替换当前 `.mini-spine-stack` 堆叠 3 本 + `+N`。
- 书名竖排单列不折行，超长截断（`overflow: hidden`），字号 10px。
- 行列头、拖拽高亮、反馈动画不变。

## Risks / Trade-offs

- [10 列关（sort-3-3）单元宽仅 ~43px] → 书脊缩至 14px、每层 1~2 本，必要时自动加层；书名截断可接受。
- [层数 = ceil(书种/容量)，书种极多时层多书矮] → 当前关卡书种 ≤ 8，层数 ≤ 2~3，可接受；不做滚动。
- [幽灵预览与实体书重叠] → 预览贴书脊后/最低空层末尾，虚线描边区分。
- [书脊固定宽 20px 下 6+ 种书溢出] → 自动加层兜底，符合"单层优先、放不下升层"设计。
## Migration Plan

- 纯前端替换，无数据迁移。改动文件：`SortGrid.vue`（分层算法 + 书脊视觉 + 幽灵）、`MatrixGrid.vue`（格内书脊角标）、必要时 `GameView.vue`（面板宽度微调）。
- 验证：`npm run build` + Playwright 回归（分层/角标/幽灵/矩阵格）。
- 回滚：还原上述文件 git 变更即可。
